Warp ZTNA 引擎服务

本包安装 Warp ZTNA 引擎服务，不含桌面界面。继续安装前，按本机现状对照：

  • 本机已安装引擎服务：按升级处理——停旧服务、换本包引擎、重新注册并启动（服务短暂中断）；状态目录（/var/lib/warp-ztna，本机入网身份所在）与配置目录（/etc/warp-ztna）默认保留。例外：本包预置了入网配置（/etc/warp-ztna/enroll.conf）时，安装会先清空旧的本机入网状态再按下发目标入网；未预置入网配置、但本机旧配置指向其他管理服务器时也会清空（当前激活的整份清空，其余残留 profile 单独移除）——应用将以产品默认管理服务器开始。升级同时会清理旧版引擎残留目录（/etc/netbird 等）中指向其他管理服务器的旧配置——新版引擎在原配置缺失时会自动搬运它，留着会让旧连接复活。以上清理均不影响对端已有记录。
  • 尚未安装：直接安装即可。

装完后，把同一镜像里的 Warp ZTNA 应用拖入 Applications 即可使用。
