# Warp ZTNA Client

Warp ZTNA desktop client「零通」与 routing-peer 包的**构建与分发面**：Tauri 2 桌面应用（`agent/warp-ztna-app`）、
引擎打包与安装脚本（`agent/warp-ztna`）、客户端侧公共 crate（`libs/warp-ztna-*`）。

> This repository is **generated by CI** as a mirror of a private repository and serves as the
> build and release surface for the Warp ZTNA client. Development, review and architecture
> docs live in the private repository; changes pushed here are overwritten by the next sync.

## 目录

| 路径 | 内容 |
|---|---|
| `agent/warp-ztna-app` | Tauri 2 桌面应用（React 前端 + `src-tauri`） |
| `agent/warp-ztna` | 引擎归档与安装脚本（`install.sh` / `install.ps1`）、macOS `.pkg` 组装、离线 smoke 测试 |
| `libs/warp-ztna-{cfg,err,nbrpc}` | 客户端依赖的公共 crate |
| `deploy/client-pkg` | Release 资产组装脚本 |
| `deploy/client-pkg/scripts` | 卸载 Warp / 清理旧引擎脚本（先 `--dry-run` / `-DryRun`） |

## 构建

- 前端与桌面：Node 24 + pnpm 10（`pnpm install && pnpm --filter @warp-ztna/app build`），
  桌面打包需 Rust 1.95 与 `pnpm --filter @warp-ztna/app tauri build`。
- 客户端 Rust 检查：`cargo clippy --locked -p warp-ztna-app --all-targets -- -D warnings`、`cargo test --locked -p warp-ztna-app`。
- 脚本离线 smoke：`sh agent/warp-ztna/tests/smoke.sh`。

## 发布与取件

- 发布 tag 为 `client-v<包版本>`；产物发布在本仓的 GitHub Release（资产含 `.dmg`、`.pkg`、`.msi`、`.deb`、`.rpm`、
  六平台引擎归档、四个安装脚本与覆盖全部资产的 `checksums.txt`）。
- 取件基址：`https://github.com/dayu-sec/warp-ztna-client/releases/download`，脚本按 `client-v<版本>/<资产名>` 取。
- 校验：下载全部资产后在其所在目录执行 `sha256sum -c checksums.txt`。

## 卸载

完整卸载与旧引擎清理脚本在 `deploy/client-pkg/scripts/`。macOS / Linux 先加 `--dry-run`、Windows 先加 `-DryRun` 看将执行的动作；默认保留 state，`--purge` / `-Purge` 才删。各平台安装页有对应说明。
